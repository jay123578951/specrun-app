Markdown Reading

詳情面板的閱讀區：IBM Plex Sans TC、15px、行高 1.85、內文欄寬 68ch。

Why

specrun-app（OpenSpec 相容的桌面 spec 管理 App）目前只有 roadmap 與規格目錄，沒有可執行的程式骨架。後續所有功能 change（change 列表、artifact 渲染、watcher 等）都需要一個跑得起來的專案環境作為地基。

What Changes

  • 建立 pnpm 專案與單套件結構，前端 Vite + Vue 3 + TypeScript + Pinia
  • 本地後端 Nitro server，提供第一支 GET /api/health 端點驗證前後端通路
  • 樣式工具安裝 UnoCSS，僅裝 preset 與管線，不定義任何 design tokens

不包含任何視覺設計決策——tokens、配色、字階、明暗主題由 D1 change 專門處理。
